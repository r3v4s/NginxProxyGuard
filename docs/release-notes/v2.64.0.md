## 새 기능

- URI 차단 예외, 우선 허용, 레이트 리밋 예외, 전역 신뢰 IP에도 IP와 함께 도메인(DDNS 이름 등)을 넣을 수 있습니다. 접근 목록의 도메인처럼 NPG가 주기적으로 다시 조회해 지금 가리키는 주소에만 적용합니다.
- 이 목록들의 도메인은 밴(fail2ban·WAF 자동 차단 포함), WAF, 필터 구독의 IP 차단을 넘지 못합니다. IP로 넣은 우선 허용·전역 신뢰와 달리 WAF를 끄지 않습니다.

## 알아둘 것

- 이전 버전으로 되돌리거나 이 버전의 백업을 이전 버전에 복원하면 이 목록들의 도메인은 적용되지 않습니다.
- 이전 버전에서 우선 허용이나 전역 신뢰 IP에 IP 대신 이름으로 저장된 항목은 여전히 효과가 없습니다. 이제 "적용되지 않는 항목"으로 보이고, "도메인으로 옮기기"로 도메인으로 바꿀 수 있습니다. 두 IP 칸에 새로 넣는 값은 IP·CIDR만 받습니다.

## 고침

- 도움말 팝업 일곱 개(프록시 호스트의 접근 목록·fail2ban·URI 차단·인증서, WAF 테스트의 세 칸)가 설명 대신 번역 키를 보이던 문제.
- Synology NAS처럼 커널이 오래된 장비에 새로 설치하면 관리 화면(npg-ui)이 `bind() to 0.0.0.0:443 failed (13: Permission denied)`로 뜨지 않던 문제. 이미 설치했다면 docker-compose.yml의 `ui` 서비스에서 `security_opt:`와 `- "no-new-privileges:true"` 두 줄을 지우고 `docker compose up -d` 하세요.

> docker compose pull && docker compose up -d
> ```

## New

- URI block exceptions, priority allow, rate limit exceptions and the global trusted IPs can hold domains (a DDNS name, for example) beside IPs. As with access lists, NPG looks them up again on a schedule and applies them only to the addresses they point to now.
- A domain in these lists never gets past bans (fail2ban and WAF auto-ban included), the WAF or the IP blocks of filter subscriptions. Unlike an IP entry, a priority allow or trusted domain does not turn off the WAF.

## Good to know

- If you go back to an older version, or restore a backup of this version on an older version, the domains in these lists are not applied.
- Entries an older version saved with a name instead of an IP in priority allow or the global trusted IPs still do nothing. They now show as "Entries not applied", and "Move to domain" turns one into a domain. A new entry in those two IP fields must be an IP or a CIDR range.

## Fixed

- Seven help popups (the access list, fail2ban, URI blocking and certificate tips of the proxy host form, and the three WAF tester fields) showed their translation key instead of the text.
- On hosts with an older kernel, such as a Synology NAS, the admin UI (npg-ui) of a new install did not start (`bind() to 0.0.0.0:443 failed (13: Permission denied)`). If you already installed, delete the `security_opt:` and `- "no-new-privileges:true"` lines of the `ui` service in docker-compose.yml, then run `docker compose up -d`.
