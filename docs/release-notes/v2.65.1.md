## Fixed

- In English, the proxy host edit dialog cut off its last tab, Advanced. On a narrow screen such as a phone, the tabs that were cut off can now be reached by scrolling the tab row sideways.
- The API docs (swagger) were missing `GET /api/v1/filter-subscriptions/match`, which finds the filter subscriptions that list an IP or a user-agent.

> Thanks to **@theAmberLion** for reporting the cut-off tab (#336) and **@four2mis** for reporting the missing API docs (#337).
