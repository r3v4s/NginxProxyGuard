## 새 기능

- 인증서 발급용 DNS 제공자에 IONOS를 추가했습니다. API 키의 접두사와 비밀 키는 각 칸에 따로 입력하세요.

## 보안

- nginx를 1.30.6으로 올려 보안 문제 다섯 건을 고쳤습니다. NPG가 만드는 설정에서 영향을 받는 것은 HTTP/3를 켠 프록시 호스트, SSL을 켠 리다이렉트 호스트(HTTP/3가 늘 켜져 있습니다), 전역 설정의 SSL/TLS에서 Session Tickets를 켠 설치입니다.

> IONOS를 더해 주신 **@Fr3d0r** 님(#332)과 nginx 보안 업데이트를 알려 주신 **@tasoo-oos** 님(#333) 감사합니다.

---

> ```bash
> docker compose pull && docker compose up -d
> ```

---

## New

- IONOS is now a DNS provider for certificates. Enter the API key prefix and the secret in their own fields.

## Security

- nginx is updated to 1.30.6 for five security fixes. In the configs NPG generates, the affected ones are proxy hosts with HTTP/3 on, redirect hosts with SSL (they always accept HTTP/3) and installs with Session Tickets on in the global SSL settings.

> Thanks to **@Fr3d0r** for adding IONOS (#332) and **@tasoo-oos** for flagging the nginx update (#333).
